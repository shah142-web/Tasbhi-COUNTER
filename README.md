⏱️  Tasbhi Counting Web Application

My First JavaScript Project 🚀

Welcome to my first web development project! This Stopwatch is a simple and interactive web application built using HTML, CSS, and JavaScript.

This project is an important step in my coding journey. It helped me understand JavaScript functions, events, and DOM manipulation.

🌟 Features

- ▶️ Start the counter
- ⏸️ Stop the timer
- 🔄 Reset the counter
- ⏱️ Real-time time tracking
- 🎨 Simple and attractive user interface
- 📱 Beginner-friendly design

🛠️ Technologies Used

- HTML5 – To create the structure.
- CSS3 – To design and style the stopwatch.
- JavaScript – To make the stopwatch functional.
